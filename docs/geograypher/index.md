# Tools

!!! tip "Looking for end-to-end workflows?"

    The [data processing tutorials](../tutorials/index.md) walk through real data processing workflows that use and connect multiple OFO tools.

Find documentation for all of our tools in each tool-specific documentation site or GitHub repository:

- [Automate Metashape](https://github.com/open-forest-observatory/automate-metashape): running reproducible, configurable photogrammetry workflows in Agisoft Metashape to produce data products from drone imagery
- [Geospatial Data Registration Toolkit (GDRTK)](https://github.com/open-forest-observatory/geospatial-data-registration-toolkit): aligning slightly misaligned raster datasets, such as orthomosaics from different dates or a drone-derived canopy height model and a third-party terrain model
- [Tree Detection Framework (TDF)](https://open-forest-observatory.github.io/tree-detection-framework/): detecting and delineating individual trees from drone-derived data products
- [Geograypher](https://open-forest-observatory.github.io/geograypher/): translating between pixel coordinates in raw drone images and geospatial coordinates
- [Tree Classification Framework (TCF)](https://github.com/open-forest-observatory/tree-classification-framework): predicting tree attributes, such as species and live/dead status, from raw drone photos
- [Tree Registration and Matching Toolkit (TRAM)](https://github.com/open-forest-observatory/tree-registration-and-matching): spatially aligning, matching, and comparing tree maps
